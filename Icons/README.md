# 🎨 Icons

The folder icons used in my **windots** setup, featuring the [Catmocha Icon Theme](https://www.deviantart.com/digifeye/art/Catmocha-Icon-Theme-1261586793) by **Digifeye**.

These icons are applied system-wide using Windhawk's **Resource Redirect** mod to give Windows folders a consistent Catppuccin-inspired appearance.

## 🛠️ Details

- **Icon pack:** [Catmocha Icon Theme — Digifeye](https://www.deviantart.com/digifeye/art/Catmocha-Icon-Theme-1261586793)
- **Tool:** [Windhawk](https://windhawk.net/)
- **Mod:** Resource Redirect

## 📦 Setup

1. Install [Windhawk](https://windhawk.net/).
2. Install the Resource Redirect mod.
3. Download the Catmocha icon pack from the link above.
4. Configure Resource Redirect to use the icon theme and follow the mod's instructions to refresh the icon cache.
